# Inbox

The **Inbox** is where openkoutsi tells you things. It sits in the sidebar, and
carries a badge with the number of messages you haven't read yet.

Most of what lands there is about your own training — a new achievement, for
example. If you administer the instance, you also get messages about events on
it, such as someone joining through an invite link.

## Reading a message

Click a message to open it. The full text appears in a card on top of the page,
and the message is marked as read.

Messages you've already read stay in the list, slightly dimmed. You can open them
again as often as you like — reading one is not a one-off.

!!! tip
    **Mark all read** clears the unread badge in one go, without opening
    anything.

## Achievement messages

When you earn one or more badges, openkoutsi sends a single message about the
whole batch — never one message per badge, even if back-filling a season of old
rides earns you a dozen at once.

The message names every badge you earned and how far you got:

> **3 achievements unlocked**
>
> You earned:
>
> - Getting started — 1 activity
> - Long hauler — 6 h
> - Climber — 1000 m

Open it and use **View achievements** to jump straight to the
[Achievements & streaks](achievements.md) page and see them in context.

## Deleting messages

The bin icon on a message deletes it.

!!! warning
    Deleting is permanent. There is no archive and no undo — the message is
    really removed from your mailbox.

Messages live in your own per-user store, so nobody else can read yours, and
deleting one doesn't affect anyone else's copy.

!!! info "Language"
    Message text is written when the message is sent and stored as-is, so it is
    currently always in English even if you use openkoutsi in Finnish. The rest
    of the inbox — buttons, labels, the page itself — follows your chosen
    language as usual.
